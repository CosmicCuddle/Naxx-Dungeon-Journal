# Naxx Dungeon Journal

A work-in-progress **World of Warcraft 3.3.5a** dungeon journal built for the Naxxramas server.

The addon is designed to provide an in-game reference for Vanilla, The Burning Crusade and Wrath of the Lich King dungeons, with dedicated sections for trash, bosses, quests, preparation and maps.

## Current status

**v0.2.1 TEST**

This repository currently contains the visual/data test build. It is still under active development and some dungeon data, boss information, loot tables and map support are not yet complete.

## Commands

- `/dj`
- `/dungeonjournal`

## Installation

1. Close World of Warcraft.
2. Copy the `DungeonJournal` addon folder into `World of Warcraft/Interface/AddOns/`.
3. Start WoW and enable **Dungeon Journal** on the AddOns screen.
4. Use `/dj` in game.

## Compatibility

- World of Warcraft 3.3.5a
- Interface: 30300
- Server-specific build for Naxxramas
